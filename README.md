# 📜 עורך השיעורים — סקיל ל-Claude Code

הופך תמלול של שיעור, דרשה או הרצאה למסמך Word ערוך ומסודר — עם כותרות, פסוקים
מנוקדים ומקורות מדויקים.

## מה זה עושה

אתה נותן לו תמלול גולמי — הוא מחזיר מסמך שאפשר להדפיס ולחלק:

1. מנקה חותמות זמן, גמגומים, מילות מילוי וכפילויות.
2. מתקן שגיאות דקדוק, כתיב ושיבושי תמלול.
3. מארגן את החומר בכותרות ותת-כותרות לפי נושאים.
4. כותב בגוף ראשון — כאילו אתה מוסר את השיעור.
5. מזהה כל פסוק, כותב אותו **מנוקד ובמלואו** ומוסיף מקור מדויק (ספר, פרק, פסוק).
6. בונה קובץ Word בעברית — RTL מלא, גופן David, שחור-לבן, מספרי עמודים.

> **זה לא מסכם ולא מקצר.** כל נושא, כל משל וכל דוגמה מהמקור נשארים — רק בעברית
> תקנית ומסודרת. ההיקף של התוצר דומה להיקף המקור.

## שלוש דרכים להזין שיעור

- **קישור יוטיוב** — הסקיל מוריד את הכתוביות בעצמו, בלי להוריד את הווידאו.
- **קובץ תמלול** — כל קובץ טקסט, גם עם חותמות זמן ושגיאות.
- **קובץ Word** — אם כבר העתקת את התמלול למסמך.

## התקנה (מומלץ)

פותחים את Claude Code ומדביקים:

```
הי קלוד! התקן לי בבקשה את סקיל "עורך השיעורים" (shiur-editor).
1. זהה את מערכת ההפעלה שלי ואת הנתיב ~/.claude/skills/ (ב-Windows: C:\Users\<user>\.claude\skills\). צור את התיקייה אם אינה קיימת.
2. הורד את החבילה: https://hiyabh.github.io/claude-shiur-editor-skill/shiur-editor-skill.tar.gz
3. חלץ ממנה את שתי התיקיות — shiur-editor וגם youtube-transcript — אל ~/.claude/skills/. אל תדרוס סקיל קיים בלי לשאול אותי.
4. הרץ את בדיקת ההתקנה: python "~/.claude/skills/shiur-editor/scripts/preflight.py" (פתור את הנתיב עם os.path.expanduser, אל תסמוך על ~ במעטפת). מסור לי את הדוח בעברית, ואם חסר משהו — תגיד לי בדיוק מה להתקין.
5. הסבר לי בקצרה איך מפעילים: שאני פשוט אומר "ערוך לי את השיעור הזה" ומצרף קישור יוטיוב או קובץ תמלול.
```

## התקנה מהטרמינל

```bash
curl -L https://hiyabh.github.io/claude-shiur-editor-skill/install.sh | bash
```

או ידנית:

```bash
curl -L -o shiur.tar.gz https://hiyabh.github.io/claude-shiur-editor-skill/shiur-editor-skill.tar.gz
mkdir -p ~/.claude/skills
tar -xzf shiur.tar.gz --strip-components=1 -C ~/.claude/skills
```

בשני המקרים סקיל קיים באותו שם **לא נדרס** — הוא מדולג בהודעה.

אחרי ההתקנה, הפעל מחדש את Claude Code כדי שיזהה את הסקיל.

## שימוש

פשוט תגיד לקלוד בעברית:

- `ערוך לי את השיעור הזה` + קישור יוטיוב
- `ערוך תמלול שיעור` + שם קובץ
- `ערוך דרשה` / `הכן שיעור להדפסה`

## תלויות

| מתי | מה | גודל |
|---|---|---|
| **תמיד** | `python-docx` | שניות |
| **מסלול יוטיוב** | `yt-dlp`, `youtube-transcript-api` | שניות |
| רק כשאין כתוביות עברית | `faster-whisper` + `ffmpeg`/`ffprobe` ב-PATH + מודל עברית | ~1.6GB, פעם אחת |

בדיקת ההתקנה אומרת בדיוק מה חסר ומה הפקודה להתקין:

```bash
python -c "import os;print(os.path.expanduser('~/.claude/skills/shiur-editor/scripts/preflight.py'))"
# ואז להריץ את הנתיב שהודפס
```

ffmpeg (רק למסלול Whisper): `winget install Gyan.FFmpeg` · `brew install ffmpeg` ·
`sudo apt install ffmpeg`.

**הערה על yt-dlp:** כשיוטיוב חוסם, הסקריפט מריץ `pip install --upgrade yt-dlp`
מעצמו — זה מה שפותר את זה בפועל. בסביבה מנוהלת (PEP 668) הוא מדווח וממשיך עם
הגרסה הקיימת. לביטול מוחלט: `SHIUR_NO_PIP=1`.
